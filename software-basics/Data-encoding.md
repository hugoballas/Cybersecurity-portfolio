#### examples of ASCII

* ASCII code in decimal for @: 64
* Character that has ASCII code of 35 in decimal: #
* Name of the character that has code of 7 in ASCII: BEL


### Unicode

Unicode is a universal character encoding standard. It assigns unique code points to characters from all modern and historical writing systems worldwide.

#### examples of unicode

* U+0041 = Latin “A”
* U+03A9 = Greek “Ω”
* U+3042 = Japanese Hiragana “あ”
