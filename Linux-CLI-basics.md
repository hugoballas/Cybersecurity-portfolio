### CLI: command-line interface

#### commands:
* pwd
* ls
* ls -l
* ls -al
* cat (ler o ficheiro)
* find ~ -name "nomedoficheiro"
* whoami (saber username)
* uname -a (saber OS, kernel version, arquitetura). exemplo:
								Linux: The system is running the Linux kernel.
								tryhackme: The hostname (the computer’s name).
								<REDACTED>-aws: The kernel version installed on the machine.
								x86_64: The hardware platform (also 64-bit).
								GNU/Linux: The operating system type (Linux kernel + GNU tools).
	df -h (disco e espaço)
	ssh username@192.168.1.10 (conectar, usar comandos num "pc" estando remoto)
	su - "user" (quando estou logado num user e quero logar noutro)
	su - root (mudar para a conta root)
